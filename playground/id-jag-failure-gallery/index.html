The happy path, for reference

Every scenario below starts here. Four steps, per xaa.dev:

1 · Sign inUser authenticates to the requesting app via the enterprise IdP (SSO).
2 · ID-JAG issuedApp trades the ID token for a signed ID-JAG — if enterprise policy allows.
3 · ExchangeResource AS validates the ID-JAG and issues an access token.
4 · API callApp calls the protected API. No consent screens, no user clicks.
