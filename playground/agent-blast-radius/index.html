💥 Agent Blast Radius

Three attacks. One stolen credential each. Run them, watch the damage spread across the network — then flip the scoping toggle and watch the blast radius shrink.

Simulated attacks · illustrative timings — v2 of the Auth Playground

v1 showed you where enforcement lives — the aud, exp, and scope claims that kill bad grants. v2 shows you what happens when it doesn't. Same three claims, now from the attacker's side of the table.

How to use this: pick a scenario, run the attack with the credential overprivileged (as these things usually are), then flip to least-privilege and run it again. Watch the tally. The theft is identical both times — the scoping decides the outcome.

The pattern

  • Speed without witnesses. Agents act at machine speed with no human watching. Detection time — not prevention — is the cost multiplier. Four hours versus six days.
  • Delegation multiplies. Every agent-to-agent call extends the blast radius. Audience binding (aud) is what breaks the chain.
  • The defenses are boring — and they're the v1 claims. Narrow scope. One audience. Short expiries. Nothing here requires a new product; it requires minting credentials like you mean it.
